# Security Policy

## Supported Versions

NOXFORT EDGE GATEWAY is under active development and production deployment. Only the latest released tags and `main` branch receive official security patches.

| Version | Supported          |
| :---    | :---:              |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

> [!CAUTION]
> **CRITICAL INFRASTRUCTURE WARNING:**  
> The **NOXFORT EDGE GATEWAY** acts as the perimeter ingress and TLS gateway for urban traffic controllers, municipal CCO videowalls, and emergency vehicle preemption (EVP) systems. Vulnerabilities in TLS termination, SNI routing, or authentication forwarding can compromise municipal safety operations.

**DO NOT disclose vulnerabilities publicly on GitHub Issues.**

If you discover a potential security flaw, please report it privately:

1. **Email:** Contact the security team at **security@noxfort.com** *(Noxfort Systems Security Team)*.
2. **Details:** Include a detailed description of the vulnerability, reproduction steps or Proof-of-Concept (PoC), and affected versions.
3. **Response SLA:** We acknowledge vulnerability reports within **48 hours** and provide triage updates at regular intervals.
4. **Coordinated Disclosure:** We adhere to responsible coordinated disclosure guidelines. Security researchers will be credited upon release of the security advisory (unless anonymity is requested).
